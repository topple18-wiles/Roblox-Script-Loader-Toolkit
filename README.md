## FAQ

### What is XCutors?

XCutors is a curated collection of popular Roblox executor and script loader tools bundled together for convenience. It includes Volt, Synapse Z, Potassium, Wave, and a universal loader called xcutorsLoader.

### Is XCutors free to use?

Yes. All executors and the universal loader included in XCutors are provided free of charge. Always download from the official GitHub repository to avoid tampered files.

### Which Windows versions are supported?

XCutors supports Windows 10 (version 1903 and later) and Windows 11. Both x86 and x64 architectures are supported.

### Do I need to disable my anticomponent?

Some anticomponent programs may flag script executors as potentially unwanted programs. You may need to add an exclusion for the XCutors folder. Always ensure you download from the official repository.

### Can I use my own custom Lua scripts?

Absolutely. You can load any Lua script file from your local machine or paste script code directly into the executor's built-in editor.

### How do I update to the latest version?

Visit the Releases page on the GitHub repository, download the newest ZIP, and extract it over your existing installation. Your saved profiles and settings will be preserved.

### What executors are included in the pack?

The pack includes Volt, Synapse Z, Potassium, Wave, and the xcutorsLoader universal loader that lets you manage and switch between all of them.

### The executor is not injecting. What should I do?

Make sure Roblox is fully launched and you are in a game. Run the executor as administrator. If the issue persists, check that your anticomponent is not blocking the process and that you have the latest version of XCutors.

### Is XCutors open source?

The loader and repository infrastructure are open source. Individual executors may have their own licensing terms; please refer to each executor's documentation for details.

### Where can I find scripts to use?

XCutors includes a built-in script browser with a curated library. You can also find community scripts on popular Roblox scripting forums and repositories.
